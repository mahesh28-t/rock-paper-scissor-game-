# 🎮 Rock Paper Scissors

A simple and interactive **Rock Paper Scissors** game built using HTML, CSS, and JavaScript.

Play against the computer, track your scores, and challenge yourself!

---

## ✨ Features

- 🪨 Rock, Paper, and Scissors gameplay.
- 🤖 Random computer moves.
- 🏆 Automatic win, lose, and tie detection.
- 📊 Real-time score tracking.
- 💾 Score persistence using Local Storage.
- 🔄 Reset score functionality.
- 🎨 Custom dark-themed UI with hover effects.

---

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| HTML5 | Structure of the game |
| CSS3 | Styling and visual design |
| JavaScript | Game logic and functionality |
| Local Storage | Saving scores after page refresh |

---

## 🚀 How to Play

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html` using Live Server.
4. Choose Rock, Paper, or Scissors.
5. Play against the computer and track your score.
6. Use the Reset Score button to start again.

## 💾 Local Storage

This project uses browser Local Storage to preserve the game score even after refreshing the webpage.

- `localStorage.setItem()` – Saves the score.
- `localStorage.getItem()` – Retrieves the saved score.
- `JSON.stringify()` – Converts the score object into a string.
- `JSON.parse()` – Converts the stored string back into a JavaScript object.
